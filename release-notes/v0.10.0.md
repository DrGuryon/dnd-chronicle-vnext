# D&D Chronicle vNext 0.10.0

Milestone 10 přidává globální D&Dpedii a třetí generaci pravidlových balíčků:

- globální katalog fungující i bez aktivní kampaně, s fulltextovým hledáním, filtry, řazením a stránkováním přímo v SQLite;
- oddělené verze pravidel 2014 a 2024, typované detaily a související záznamy;
- jednotný zdroj detailu pro D&Dpedii, Entity Cards a AI čtecí nástroje;
- přístupný responzivní dialog detailu, klávesnicové ovládání, návrat fokusu a úplné loading/empty/error stavy;
- Rules Pack schema 3 s validací typovaného obsahu, atomickou aktivací i rollbackem a samoopravným FTS indexem;
- přísnou izolaci Homebrew mezi kampaněmi a odstranění globálních definic z Knihovny kampaně;
- databázové schéma v9 se zálohou před migrací a kontrolou cizích klíčů.

Distribuovaný obsah pochází výhradně z otevřených SRD 5.1 a SRD 5.2.1 pod CC BY 4.0. Existující kampaně, postavy, konverzace a bezpečně uložený OpenAI API klíč zůstávají zachované.
