# D&D Chronicle vNext 0.8.0

Milestone 8 přináší první skutečně editovatelnou Chronicle:

- Character Builder/Editor 2.0 s rychlou i rozšířenou tvorbou;
- vyhledávatelný katalog otevřených pravidel D&D 5E 2014 a 2024;
- explicitní Homebrew cestu a bezpečné párování starých pojmů s kanonickými definicemi;
- úpravu postavy i vlastních Homebrew definic přímo z Entity Card;
- jednotné atomické DataChange transakce pro ruční i AI úpravy;
- oddělený administrativní audit bez falešných událostí příběhu;
- AI nástroje pro vyhledání definic a návrh profilových změn se schválením;
- kontrolu souběžných úprav a idempotentní použití změn;
- databázové schéma v7 se zachováním a zálohou existujících kampaní.

OpenAI API klíč zůstává uložený pouze v aplikaci stejně jako dříve; aktualizace ho nemění ani nepřenáší do databáze nebo instalátoru.
