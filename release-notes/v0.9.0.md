# D&D Chronicle vNext 0.9.0

Milestone 9 zpevňuje každodenní práci s Chronicle:

- opravený lifecycle Character Editoru bez násobení listenerů a se správným návratem fokusu;
- moderní chatové bubliny, Enter/Shift+Enter, IME-safe odesílání a composer rostoucí do osmi řádků;
- globální toast systém a nový persistentní, filtrovatelný a bezpečně exportovatelný Log;
- vztahy mezi druhy/rody a povoláními/podtřídami včetně backend validace a Homebrew parentů;
- verzované Rules Packs 2.0 pro SRD 5.1 a SRD 5.2.1, samostatný updater, SHA-256 validaci, offline bootstrap a obnovu poškozeného packu;
- turnová cache AI čtení, batch context tools a paralelní provádění pouze nezávislých read calls;
- telemetrii použití nástrojů, měkké varování při 75 % rozpočtu a bezpečné finální dokončení při limitu 12 kol / 40 volání;
- databázové schéma v8 se zachováním a zálohou existujících kampaní.

OpenAI API klíč zůstává v uživatelském bezpečném úložišti aplikace. Release ho nečte, nemění ani nepřidává do instalátoru, logu nebo rules packů.
